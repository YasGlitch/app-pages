Privacy Policy

Last updated: October 12, 2026

Overview

Personal Drive Archive is a private-use application designed to create archival copies of files stored in the application operator's Google Drive account. It is not offered as a public service.

Google Drive Access

The application requests read-only access to Google Drive files and associated metadata for archival purposes. This permission does not allow the application to modify or delete source files.

Data Collection and Use

Authorized files and metadata may be downloaded to privately managed storage for backup, preservation, integrity verification, and recovery.

Google Drive data is not sold, used for advertising, or intentionally made publicly accessible.

Data Storage and Security

Archived information is maintained on private storage controlled by the application operator. Access is managed through local security controls.

Authentication credentials and archived file contents are not published on this website.

Data Retention

Archived information is retained according to the operator's archival and retention practices. The operator controls the removal of stored copies.

Third-Party Services

Google provides authentication and Google Drive access. Rclone is used to transfer authorized data to privately managed storage.

This informational website is hosted through GitHub Pages. Archived Google Drive content is not hosted on this website.

Revoking Access

Google Drive authorization may be revoked through the connected Google Account's security settings. Revocation prevents further authorized access but does not automatically remove previously archived copies.

Contact

Questions concerning this application may be directed to the application operator using the support contact provided on Google's OAuth consent screen.
